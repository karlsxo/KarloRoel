# Karlo Roel Portfolio

Professional portfolio website for Karlo Roel Montenegro, built with Next.js and designed to showcase selected projects, technical strengths, and contact information in a clean, modern format.

## Overview

This portfolio highlights:

- Selected work, including DalAni, Artery, and Metropolis
- A concise summary of technical skills and academic focus
- A polished contact flow for recruiters and collaborators

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` - start the local development server
- `npm run build` - create a production build
- `npm run start` - run the production build locally
- `npm run lint` - run ESLint

## Project Structure

- `app/page.tsx` - main portfolio experience
- `app/layout.tsx` - document metadata and shared layout
- `app/globals.css` - global styling and visual system
- `public/` - project images and static assets

## Deployment

This project can be deployed to Vercel or any platform that supports Next.js. Before deploying, run `npm run build` to confirm the production build passes.

## Notes

The content is intentionally tailored for a professional portfolio. Replace project details, links, and contact information as your work evolves.
